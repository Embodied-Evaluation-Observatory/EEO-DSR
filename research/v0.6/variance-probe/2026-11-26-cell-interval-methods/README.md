# cell 区间方法对比（B=2,000）

日期：2026-11-26。模拟，不是语料读数，不签发记录。

## 设置

- 输入：`2026-11-26-r2/droid_cell.csv.gz`；K=53,714，N=93,994，multi=6,602。
- 每个真 ρ 1,000 次模拟；每次 B=25/100/500/2,000 嵌套前缀重抽。
- 点估计：固定 6,602 个多例子群上的 Multinomial 重抽；区间只用多例子群。
- 方法：percentile、basic、normal、BC、BCa（400 点 jackknife 加速度）。
- 同一 seed 20261128；jackknife 用独立 seed，避免改变主重抽流。
- 覆盖率的 Wilson 95% 以可估点次数为分母。

## 结论

1. B 从 25 加到 2,000 仍不能把 cell 覆盖抬到 0.95；ρ=0.90 在 B=2,000 为 0.838。
2. 在 8 个 ρ 中，percentile 有 7 个优于 basic、BC、BCa；ρ=0 时 basic 覆盖 0.952，但到 ρ=0.90 跌到 0.739。
3. BC 与 BCa 只轻微改变分位，不能修复偏斜：ρ=0.90 为 0.824／0.819，仍低于 percentile。
4. 结论不是“换一个区间名字就好”。当前证据显示 percentile 仍是这四个里最好的；但它在高偏斜下系统性偏窄。G2 未关闭，ICR 不能建立在这个区间上。
5. 下一步不是继续加 B，也不是把 BCa 当修复；要么改估计量／区间构造（studentized、m-out-of-n、方差稳定变换），要么在记录里明写实际覆盖并禁止按名义 0.95 使用。

## 边界

- 这是 cell 尺寸分布上的模拟，不是某个真实 cell 的推断。
- 覆盖率条件于可估点；零方差/不可估点不计入分母。
- `nees_record: not_issued`；`icr_record: not_issued`。
