# B-sweep：簇级 bootstrap 的 B 稳定性

日期：2026-11-26。这是本地研究读数，不是发布结果，也不签发 NEES 记录。

## 口径

- 轴：`scene_id|building|robot_serial`，K=2,220，N=73,413。
- 方法：对观测语料做簇级 bootstrap，重采样簇；每个 replicate 计算一次 ICC(1)；取 2.5/97.5 percentile。
- B：bootstrap replicate 数，取值 100、250、500、1,000、2,000、5,000、10,000。
- 所有 B 共用 seed 20261126，B 较小者是同一随机流的前缀。
- 这不是 G2 的覆盖率模拟；B-sweep 只测“观测语料上的区间端点随 B 是否稳定”。

## 采用值

B=2,000 作为论文主读数：相对 B=10,000，下界偏 +0.000609、上界偏 +0.000436、区间宽偏 +0.000173。B=1,000 的上界偏 +0.001132，约为 B=2,000 的 2.6 倍；B=100 的上界偏 +0.004486。

B=100 与 B=250 的宽度反而大于 B=500，属于有限 B 的分位噪声，不构成“B 越小越宽”的单调结论。

## 文件

`b100.json`、`b250.json`、`b500.json`、`b1000.json`、`b2000.json`、`b5000.json`、`b10000.json` 是逐 B 的原始输出；`b-sweep.json` 是汇总。`tools/icc_bootstrap.py` 生成，未改工具。

## 边界

- 只覆盖 composite native 轴；site 与 cell 轴未做 B-sweep。
- 只回答区间端点稳定性，不回答覆盖率；G2 仍未关闭。
- `n_eff` 条件区间只留在 JSON，不进入对外材料。
