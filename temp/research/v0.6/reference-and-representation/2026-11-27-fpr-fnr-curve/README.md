# FPR / FNR vs W 曲线

> **FNR 的目标类：本文件只测 `re-encoded` 类（150 对 0.5% + 150 对 2% 受控重编码）。`exact` 类是字段级重复，`n_exact_copies=58`，与 W 无关；`near-take` 类未定义、未测量。不得把本文件的 FNR 当成 `near-take` 的召回率。定义见 `../2026-11-27-equivalence-classes/`。

日期：2026-11-27。样本：`2026-11-27-droid-sample`，成功 1,999 / 2,000；表示按 `summary` 203 维、`traj16` 464 维，指纹投影 `dims=32`；硬负例 246 条，正例 300 对（150 对 0.5% 重编码 + 150 对 2% 重编码）。

**这不是去重工作点。** 曲线只展示同一批受控重编码正例与硬负例上的取舍；`W` 由买方按自己的误报预算声明，EEO 不代选。正例是重编码副本，不是独立重采样的真实重复。所谓“真实正例缺口”已改写为三个等价类的定义缺口：`exact` 58 组、`re-encoded` 150+150、`near-take` 未定义；本文件只测 `re-encoded`。

## 关键格

| 表示 | W | FPR | FNR | 0.5% 副本 FNR | 2% 副本 FNR |
|---|---:|---:|---:|---:|---:|
| summary | 0.90 | 2/246 = 0.0081 | 101/300 = 0.3367 | 5/150 = 0.0333 | 96/150 = 0.6400 |
| traj16 | 0.90 | 0/246 = 0.0000 | 60/300 = 0.2000 | 0/150 = 0.0000 | 60/150 = 0.4000 |

`traj16` 的 `0/150`（0.5% 副本 FNR）与 `2/246`（summary 的 FPR）的 Clopper–Pearson 上界分别是 1.98% 和 2.54%；它们**是上界，不是工作点读数**。不能把 `0/150` 读成“真实重复 FNR=0”。

## 曲线

全网格见 `fpr-fnr-vs-w.csv` 与 `curve.json`。W 从 0.70 到 0.99，步长 0.02，最后一格 0.99。

- summary：W 从 0.99 降到 0.70，FPR 从 0.000 升到 0.187，0.5% 副本 FNR 从 0.580 降到 0.000；2% 副本 FNR 从 0.853 降到 0.327。
- traj16：W 从 0.99 降到 0.70，FPR 从 0.000 升到 0.041，0.5% 副本 FNR 从 0.327 降到 0.000；2% 副本 FNR 从 0.847 降到 0.087。

曲线本身说明取舍是单调的：降 W 换低 FNR，代价是 FPR 上升。买方可以按自己的误报预算在曲线上选点，而不是接受 EEO 的默认 W。

## 边界

- 硬负例与正例均来自同一 1,999 条样本；未引入买方语料。
- 重编码副本由受控变换生成，不是独立采集的重复轨迹。
- `2%` 副本的 FNR 明显高于 `0.5%` 副本；这不是方法失效，而是噪声改变了内容。
- 正例与负例的抽样数固定为 150/150×2 与 246；区间只反映该抽样，不反映语料总体。

## 两个限定

1. **重编码分布不是合成自测的 0.99997。** 0.5% 副本的 summary 中位余弦约 0.981、2% 副本约 0.810；traj16 分别约 0.995 与 0.935。它说明“近乎必然通过”的门在真实重编码上不存在。但这是 `re-encoded` 类的分布，不代表 `near-take` 类；near-take 未定义、未测量。
2. **traj16 在整个网格上支配 summary，但不等同于“表示选择比 W 选择更重要”。** 本管线两者都被投影到 `dims=32`，输出维度相同；差异来自输入表示（464 维时序点 vs 203 维摘要统计），不是简单“维度越高越好”。要支持“表示选择比 W 更决定性能”，需要同维度、同信息量的表示消融；当前只能报“在本网格上 traj16 的 FPR/FNR 全面优于 summary，2% 副本 FNR 仍为 0.40”。
