# 阈值声明表（一页）

填好这一页，核验即可按买方自己的口径重跑；不填则回落到默认套餐，且记录明确标注"不得作为验收判定依据"。

| 项 | 取值 | 依据（文件、条款或邮件编号） |
|---|---|---|
| 配对策略 `pairing_policy` | 最近邻 / 零阶保持 | |
| 配对方向 `pairing_direction` | 相机帧配状态样本 / 状态样本配相机帧 / 双向 | |
| τ 周期基准 `period_basis` | 被采样那条流 / 最短流（方向不明时，取最严） | |
| 被采样流周期（ms） | | |
| 最短流周期（ms） | | |
| τ（ms） | 由策略与周期推出，或写明约定 | |
| τ 范围 `tau_scope` | 全局（本版简化，须注明最严对流强加给所有对） | |
| m | 默认 3，可另声明 | |
| 去重度量 | 固定：episode 嵌入余弦；W 绑定在该统计量上 | |
| 去重阈值 W | 默认 0.95，可另声明 | |
| 去重标定 runner 与夹具 | 须报已知重复/相异对的误判率 | |
| 声明方 `declared_by` | 买方 / 供应商 / 双方 | |
| 是否用于验收 `acceptance_use` | 是（须自行声明）/ 否 | |

签名与日期：____________________

说明：τ = `tau_factor` × 周期。最近邻配对 `tau_factor = 0.5`（最近样本最多半周期远），
零阶保持 `tau_factor = 1.0`（保持样本最长一整个周期）。系数由策略推出，不是约定常量。
声明表随记录归档；改动即新版本、新记录，不在原地修改。
