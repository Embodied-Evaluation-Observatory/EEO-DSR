# 样本框声明（模板）

委托样本必须在出数前声明它是怎么来的。两种模式，二选一。

## committed

| 项 | 填写 |
|---|---|
| 抽样规则 | 逐条写清分层、随机化与排除条件 |
| 规则哈希 | 规则文本的 sha256 |
| 随机种子 | |
| 抽样执行者 | 委托方 / 供应商 / 双方 |
| 目标样本量 | |
| 实际样本量 | |
| 分层与配额 | |

committed 框的读数按抽样量说话，仍封顶；不得替整份语料发言。

## supplier-provided

| 项 | 填写 |
|---|---|
| 提供方 | |
| 选择依据 | 供应商自述，须原文归档 |
| 偏差风险 | 明写"非随机，读数偏乐观"，并封顶 |
| 实际样本量 | |

supplier-provided 不假装是随机样本；记录在摘要与限制段明示。
